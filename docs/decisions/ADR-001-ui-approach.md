# ADR-001: Approach A (Mission Control) is the UI baseline

Status: Accepted · 2026-11-08 · Tracker: P0-03

## Decision
Build the desktop and mobile UIs from Approach A, rev 2 (`docs/mockups/a-mission-control/`).

## Borrowed from B and C
- From C: the ⌘K command palette that shows the CLI equivalent of each action (FR-30).
- From B: plain-language status sentences on cards ("Forge is writing a handoff…") as secondary text.
- From C: the requirement trace matrix in work review (already in A rev 2, view 09).

## Consequences
Every UI task in the tracker names the Approach A view it implements. The owner reviewed Approach A in detail and its rev 2 changes were also applied to B and C, so switching later stays possible.
