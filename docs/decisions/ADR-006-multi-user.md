# ADR-006: Multi-user scope for v1 (Q4)

Status: Accepted as default · 2026-11-08 · Tracker: P0-08

v1 has one owner plus any number of attributed human reviewers identified by Tailscale login. All humans can answer questions, add rehearsal findings (FR-117a) and review; only the owner approves gates and releases. Per-user roles and permissions are P9-08.
