# Find your way around

Everything in go-build-it is one click from the sidebar, and one key sequence from the keyboard. This lesson uses the **practice project**, `birdwatch`: its AI members are scripted, so nothing you do here uses an AI subscription.

## Step: Open the practice project
check: visit /projects/{practice}
show: /projects/{practice}
Open the practice project from **Projects** (it is labeled *practice*). The overview shows its purpose, its roadmap with a review gate (◆), and its team.

## Step: Jump with the keyboard
check: visit /queue
show: /queue
Press `g` then `u` to open the queue. `g` followed by a letter goes anywhere: `g p` projects, `g q` questions, `g s` sessions, `g h` history, `g l` Learn.

> **Pro tip:** press `?` on any page for every shortcut, and `/` (or ⌘K) to search projects, tasks, docs and commands at once.

## Step: Read the docs
check: visit /docs
show: /docs
Open **Docs** (`g d`). Every page here is also inside the binary, and every UI action has a CLI command: run `gbi help` to see them.

```
$ gbi docs list --json
```
