Where the data lives. Everything on this page comes from docs/tracker/tracker-data.js. The page itself never changes when status changes.

To update status, edit a task's "status" to todo, in-progress, blocked or done, change "updated" at the top, and commit. The Git / Release Manager persona will do this once go-build-it manages itself (from the end of P4).

To add or change tasks, follow the same shape: id (phase prefix), title, reqs (requirement IDs), views (Approach A mockup views such as A-v05 or A-M3), size (S/M/L), deps, done (acceptance), q (open questions it waits on).

Coverage rule: every requirement ID must map to at least one task. The Requirement coverage tab flags any that don't.

Filters and the theme choice are remembered in this browser only.
